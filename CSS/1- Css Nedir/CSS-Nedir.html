CSS'e Giriş

CSS Nedir?

CSS, Cascading Style Sheets'in kısaltmasıdır ve HTML elementlerini biçimlendirmek için kullanılır.

CSS Nasıl Eklenir?

CSS üç farklı şekilde HTML'e eklenebilir:

  • Inline CSS: HTML etiketinin içine direkt olarak yazılır.
  • Internal CSS: HTML dosyasının head bölümünde style etiketi içinde yazılır.
  • External CSS: Ayrı bir CSS dosyası oluşturularak bağlanır.
