🔍 Kod Açıklamaları ✅ Navbar (Üst Menü) .navbar → Navigasyon çubuğunu oluşturur. .navbar-expand-lg → Büyük ekranlarda menü geniş olur, küçük ekranlarda butona dönüşür. .navbar-dark bg-primary → Arka planı mavi yapar, yazıları beyaz hale getirir. .ms-auto → Menü öğelerini sağa hizalar. ✅ Breadcrumb (Navigasyon İzi) .breadcrumb → Kullanıcının bulunduğu yolu gösterir. .breadcrumb-item → Her sayfa için bir ekmek kırıntısı oluşturur. .active → Bulunduğumuz sayfayı belirtir. ✅ Pagination (Sayfalama) .pagination → Sayfalama bileşeni oluşturur. .page-item → Sayfa numaralarını içeren liste elemanlarıdır. .page-link → Sayfa numaralarını temsil eden butonları oluşturur. .disabled → Butonun tıklanamaz olmasını sağlar.
