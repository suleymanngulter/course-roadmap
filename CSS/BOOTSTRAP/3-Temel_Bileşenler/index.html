📌 Kod Açıklamaları ✅ Typography (Yazı Stilleri) .lead → Vurgulanmış büyük paragraf oluşturur. .text-muted → Soluk renkli metin yapar. ✅ Tablolar (Tables) .table → Temel tablo stilini ekler. .table-striped → Satırları dönüşümlü olarak renklendirir. .table-bordered → Hücrelere kenarlık ekler. .table-dark → Başlığı koyu yapar. ✅ Görseller (Images) .img-fluid → Görseli responsive yapar. .rounded → Görseli köşeleri yuvarlak hale getirir. ✅ Butonlar (Buttons) .btn → Bootstrap butonlarını oluşturur. .btn-primary, .btn-danger, .btn-success gibi sınıflar buton renklerini belirler. ✅ Uyarılar (Alerts) .alert → Uyarı kutusu oluşturur. .alert-warning, .alert-success gibi sınıflar farklı türlerde uyarılar oluşturur. ✅ Rozetler (Badges) .badge → Küçük etiketler ekler. .bg-danger, .bg-light gibi sınıflar rozet rengini belirler.
