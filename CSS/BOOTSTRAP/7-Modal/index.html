🔍 Kod Açıklamaları ✅ Modal (Açılır Pencere) .modal → Modal penceresini oluşturur. .modal-dialog → Modalın içeriğini belirler. .modal-header, .modal-body, .modal-footer → Modal bileşenlerini düzenler. .btn-close → Kapatma butonu ekler. data-bs-toggle="modal" ve data-bs-target="#ornekModal" → Modalı açan butonun modalı hedeflemesini sağlar. ✅ Tooltip (İpucu Metni) data-bs-toggle="tooltip" → Tooltip özelliğini etkinleştirir. data-bs-placement="top" → Tooltip'in konumunu belirler. title="Bu bir ipucu metnidir!" → Tooltip içeriğini tanımlar. JavaScript kodu ile tooltip özelliği sayfa açıldığında etkinleştirilir. ✅ Popover (Açılır Açıklama Kutusu) data-bs-toggle="popover" → Popover özelliğini etkinleştirir. title="Popover Başlığı" → Popover başlığını belirler. data-bs-content="Açıklama metni" → Popover içeriğini tanımlar. JavaScript kodu ile popover özelliği sayfa açıldığında etkinleştirilir.
