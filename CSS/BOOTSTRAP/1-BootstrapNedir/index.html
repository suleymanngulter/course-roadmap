Konu: Bootstrap'e Giriş ve Kurulum 1. Bootstrap Nedir? Bootstrap, duyarlı (responsive) ve mobil uyumlu web siteleri oluşturmayı kolaylaştıran bir CSS ve JavaScript kütüphanesidir. İçerisinde hazır stiller, bileşenler ve bir grid (ızgara) sistemi bulunur. 2. Bootstrap Nasıl Kullanılır? Bootstrap'i kullanmak için iki yöntem vardır: CDN (İnternet Üzerinden Kullanım) Yerel (Dosya Olarak İndirme ve Kullanma) Biz şimdilik en kolay yöntem olan CDN ile kullanacağız.
