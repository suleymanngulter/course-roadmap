Konu 2: Bootstrap Grid Sistemi (Izgara Yapısı) 📌 Grid Sistemi Nedir? Bootstrap'in grid sistemi, web sayfalarını düzenli ve mobil uyumlu bir şekilde tasarlamamıza yardımcı olur. 12 sütundan oluşan bir yapı kullanır. Bu sayede, farklı ekran boyutlarına uygun tasarımlar yapabiliriz. 🎯 Grid Sisteminin Temel Kuralları Tüm içerik bir "container" içinde olmalıdır. Satır (row) kullanılır ve içinde sütunlar (col) bulunur. Sütunlar (col) toplamda 12 birimi geçmemelidir. Mobil uyumlu tasarımlar için "col-sm", "col-md", "col-lg", "col-xl" gibi sınıflar kullanılır. 📌 Örnek HTML Kodu: Grid Sistemi Kullanımı Bu kod, Bootstrap'in grid sistemini kullanarak farklı sütun yapılarını gösterir. 🔍 Kod Açıklamaları ✅ .container → Sayfanın ortalanmasını sağlar. ✅ .row → Satırları oluşturur. ✅ .col-md-6 gibi sütun sınıfları → 12’lik sistemde kaç birim kaplayacağını belirler. ✅ Mobil uyumluluk sağlandı → Küçük ekranlarda sütunlar otomatik olarak alt alta sıralanır. ✅ Renk ve border eklendi → Görsel olarak daha iyi anlamak için arkaplan renkleri ve kenarlıklar eklendi.
